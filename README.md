# Fruty Batidos 🍓🍧

Página web para **Fruty Batidos**, heladería/fruvería ubicada en El Cortijo, Cali, que vende helados, batidos, jugos, fresas con crema y obleas.

Proyecto final del curso **Jóvenes Creativos**.

## ¿Qué hace esta página?

- Muestra el menú completo con precios (fresas con crema, batidos, jugos, limonadas, etc.).
- Permite al cliente armar un pedido rápido con un formulario y enviarlo directo por WhatsApp, sin necesidad de llamar.
- Tiene enlaces directos a WhatsApp y Facebook del negocio.

## Cómo abrir el proyecto

No necesita instalación ni servidor. Basta con:

1. Descargar o clonar esta carpeta.
2. Abrir `index.html` en el navegador (recomendado: clic derecho → "Open with Live Server" en Visual Studio Code).

## Estructura de archivos

```
Heladeria/
├── index.html      -> Estructura y contenido de la página (todas las secciones del menú)
├── style.css       -> Todos los estilos visuales (colores, tipografía, diseño responsive)
├── script.js       -> Lógica del formulario de pedido (arma el mensaje y abre WhatsApp)
├── img/            -> Fotos del logo y los productos
└── README.md       -> Este archivo
```

## Tecnologías usadas

HTML, CSS y JavaScript puro (sin librerías ni frameworks).
